« Sauvegarder maintenant » force l'écriture immédiate dans le navigateur (par défaut ça se fait ~4 s après chaque modification, ou en quittant l'app) — utile juste avant de fermer si tu n'es pas sûr. « Importer » ajoute un nouveau projet dans la liste de l'accueil, il n'écrase jamais celui ouvert ici. « Nettoyer » retire les provinces créées mais jamais dessinées (clics « Nouvelle » en trop) et renumérote le reste de 1 à N — vide l'historique Annuler. « Vider ce projet » efface le dessin mais garde la taille et le nom.

Export

Export complet (PNG + JSON)

Crée provinces.png (couleur↔id, à la résolution de travail du projet) + provinces.json / regions.json / countries.json, dans un dossier daté du jour (ex. Téléchargements/bme2_export_2026-09-02/). Toujours les mêmes noms de fichier : un nouvel export le même jour écrase les précédents du jour, les jours passés restent. Marche mieux sur PC (grande image). Chaque province exporte son type (terre / mer / lac), déduit de son terrain : c'est ce que le moteur lit pour savoir ce qui est de l'eau.

Comment ça marche

Chaque province est un aplat de couleur. Tu dessines par-dessus le vide : ton trait ne recouvre jamais une province voisine (sauf mode « Écraser »). Ferme le contour d'une province et l'intérieur se remplit tout seul au lever du stylet.

Peinture et Édition

En haut à gauche, un bouton bascule entre Peinture (dessiner) et Édition (remplir les infos) — son icône montre le mode vers lequel tu vas basculer. En mode Peinture, 3 petits boutons juste en dessous choisissent la couche : Provinces / Pays / Régions (touche M pour passer de l'une à l'autre au clavier).

Mode Pays

Chaque province se colore selon son pays ; les provinces sans pays restent sombres.

Mode Régions

Fonctionne comme le mode Pays : crée une région, puis peins des provinces dessus. Le pays de la région est déduit automatiquement des provinces peintes — pas de pays à choisir. Les provinces déjà sans région apparaissent en sombre.

Nouvelle régionbouton + ou N
Assignerpinceau A : clique / glisse sur les provinces
FusionnerR : touche une province → sa région est absorbée par la région active
Retirercoche « Retirer » (ou clic droit)
Choisir / prélever une régionliste déroulante, ou pipette I sur une province

Mode Édition

Tape le bouton bascule en haut de la barre (icône pinceau) pour y entrer. Choisis ce que tu édites — Province 1 / Pays 2 / Région 3.

Provincestylo terrain : choisis un terrain dans la palette du bas ([ / ] pour changer), puis glisse sur la carte — chaque province touchée prend ce terrain. Clic droit = remet « non défini ». Annuler/Rétablir marche.
Paysclique un pays → panneau à droite : nom + code 3 lettres (généré du nom, ex. France→FRA ; modifiable, vider = revenir à l'auto)
Régionclique une région → panneau à droite : nom, nombre d'habitants, notes

Les infos Pays/Région ne passent pas par Annuler/Rétablir. Tout est sauvegardé automatiquement.

Stylet : la pression fait varier l'épaisseur. Quand le stylet touche, le doigt/paume est ignoré. Le travail est sauvegardé automatiquement dans le navigateur ; utilise « Sauver le projet » pour un fichier que tu peux déplacer entre tablette et PC.
